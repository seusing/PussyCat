# 爪爪公众号功能使用说明

- **适用版本：** 当前爪爪集成的 WeRSS v1.5.2
- **更新日期：** 2026-09-08
- **适合人群：** 第一次使用公众号收录、阅读、导出功能的用户

## 路径索引

| 我想做什么 | 从哪里进入 |
|---|---|
| 第一次授权微信公众号 | 爪爪左侧“公众号” → 主导航“微信授权” |
| 添加公众号 | 主导航“订阅与文章” → “添加公众号” |
| 搜索、阅读和使用订阅链接 | 主导航“订阅与文章” |
| 导出文章 | “订阅与文章” → 右上“三横线 菜单” → “文章操作” → “导出” |
| 下载已经导出的文件 | 主导航“导出记录” |
| 使用整理、自动化或诊断工具 | 右上“三横线 菜单” |

## 一、先认清入口

### 1. 打开公众号功能

1. 在爪爪左侧找到“公众号”。
2. 第一次使用、功能尚未安装时，点击“启用公众号”。
3. 爪爪会下载一次约 356 MB 的组件。
4. 下载完成后会自动进入公众号页面。
5. 以后再打开“公众号”时，不需要重复下载。

### 2. 记住主导航和菜单

页面主导航负责四类事情：

- **订阅与文章**：添加和整理公众号、阅读文章，并取得订阅链接。
- **导出记录**：查看、下载或删除已经生成的导出文件。
- **微信授权**：扫码授权、切换微信公众号账号或刷新授权状态。
- **三横线 菜单**：进入标签、任务、自动化、设置和诊断等高级工具。

本地服务管理账号与微信授权相互独立。界面只展示“微信授权”入口，是否已完成微信授权，请以该页面显示的状态为准。

> 宽屏和窄屏下，按钮位置可能变化，但名称不变。

> “文章操作”只会在“订阅与文章”页面的三横线菜单中出现。若当前在微信授权、导出记录或其他页面，请先返回“订阅与文章”。

### 3. 本地服务管理账号和微信授权不要混淆

- 本地服务管理账号只供爪爪在本机运行公众号服务，不是微信账号。
- **微信授权** 表示当前微信公众平台会话是否有效。页面显示“未授权”时，仍需进入“微信授权”扫码。

## 二、最常用的 4 条路径

### 路径 1：完成微信公众号授权

1. 从爪爪左侧打开“公众号”。
2. 点击主导航 **“微信授权”**。
3. 点击 **“扫码授权”**。
4. 使用可登录微信公众平台的微信扫描二维码。
5. 按微信页面提示确认；这是微信公众平台会话登录，不是扫码支付，也不是小红书浏览器扩展授权。
6. 回到爪爪。扫码成功后，授权页和页面刷新读取的是同一份授权状态；需要主动确认时，可点击 **“刷新状态”**。
7. 页面显示“已授权”后，即可继续添加公众号或更新文章。

授权页面还会显示当前微信公众号资料和授权有效期。

| 按钮 | 作用 |
|---|---|
| 刷新状态 | 重新读取当前授权和账号信息 |
| 复制 | 复制页面显示的 Token |
| 切换账号 | 切换当前使用的微信公众号账号，成功后刷新状态 |
| 扫码授权 | 重新打开授权二维码 |

爪爪会沿用保存在本机的 Token 和 Cookie；公众号服务重启后，会从本机存储恢复授权状态，并按保存的到期时间判断会话是否仍然有效。刷新状态不会延长会话；微信平台使会话失效或有效期结束后，需要重新扫码授权。

### 路径 2：添加一个公众号

1. 点击主导航 **“订阅与文章”**。
2. 打开 **“添加公众号”** 下拉菜单。
3. 点击下拉菜单中的 **“添加公众号”**。
4. 任选一种方式获取公众号资料：
   - 在“公众号名称”中输入名称，从候选项里选择正确公众号；或
   - 点击 **“通过公众号文章获取”**，粘贴一篇该公众号的微信文章链接，再点击 **“获取”**。
5. 检查自动填入的公众号名称、头像、公众号 ID 和简介。
6. 点击 **“添加订阅”**。
7. 返回“订阅与文章”，在顶部公众号来源列表中选择刚添加的公众号。

如果填错了，可以在提交前点击 **“重置”** 清空表单。

> “添加订阅”是把公众号加入爪爪的本地收录列表，方便采集、阅读和导出。它不会替你在微信里发帖，也不会替你的微信账号关注该公众号。

### 路径 3：选择公众号并阅读文章

1. 进入 **“订阅与文章”**。
2. 在顶部“已订阅公众号”区域选择“全部文章”、“单篇收录”或某个公众号。“全部文章”是所有已收录文章的全览，不只包含当前已订阅来源的文章。
3. 在文章区输入关键词搜索文章。
4. 需要时使用筛选项：全部、收藏、有正文、无正文、更新中、已删除。
5. 点击文章标题：
   - 原链接模式下，在新页面打开原作者的微信文章；
   - “在应用内阅读”模式下，在爪爪内置阅读页打开正文。
6. 也可以点击文章行末的 **眼睛图标**，直接进入内置阅读。
7. 在内置阅读器中，可以点击 **“上一篇”**、**“下一篇”** 或 **“查看原文”**。
8. 点击收藏图标可收藏，再点一次可取消收藏。
9. 点击标题前的阅读状态图标，可切换已读和未读。

### 路径 4：导出文章并下载文件

1. 进入 **“订阅与文章”**。
2. 先选定导出范围：
   - 选择某个公众号，导出该范围；或
   - 勾选需要导出的文章。
3. 打开右上 **“三横线 菜单”**。
4. 在 **“文章操作”** 中点击 **“导出”**。
5. 在导出窗口中选择格式：Markdown、DOCX、JSON、CSV 或 PDF。
6. 按需要设置页数、是否保留图片和链接、文件名等选项。
7. 提交导出。
8. 点击主导航 **“导出记录”**。
9. 点击 **“刷新”**，等待新文件出现在列表中。
10. 点击文件行的下载图标获取文件。

导出尚未完成时，“导出记录”里可能暂时没有新文件，稍后再次点击“刷新”即可。

## 三、“订阅与文章”按钮速查

### 1. 顶部“已订阅公众号”列表

| 功能键 | 用途 | 使用提示 |
|---|---|---|
| 搜索公众号 | 按名称查找本地已订阅的公众号 | 搜不到时先确认是否已经添加 |
| 全部文章 | 查看所有已收录文章 | 这是文章全览，不只包含当前已订阅来源 |
| 单篇收录 | 查看通过文章链接单独收录的内容 | 不是普通公众号账号，也不等于收藏文章 |
| 全部 / 启用 / 停用 | 筛选公众号状态 | 停用的公众号仍可能显示在列表中 |
| 停用 / 启用 | 改变该公众号是否启用 | 用于暂时停止或恢复使用 |
| 复制ID | 复制该公众号的 MP ID | 适合接口或高级配置使用 |
| 删除 | 删除本地订阅记录，不同时删除已收录文章 | 操作前先导出所需内容；之后的“清理无效文章”会清理失去订阅关联的文章 |

删除本地公众号订阅不会删除原作者在微信发布的文章。

### 2. “添加公众号”下拉菜单

| 功能键 | 用途 |
|---|---|
| 添加公众号 | 按名称搜索，或通过公众号文章链接获取资料后加入本地收录 |
| 收录单篇文章 | 粘贴一篇微信文章链接，加入“单篇收录”并抓取内容 |
| 导出公众号 | 把本地公众号列表导出为 CSV 文件 |
| 导入公众号 | 从 CSV 文件批量导入公众号列表 |
| 导出OPML | 导出可供支持 OPML 的阅读工具使用的订阅清单 |

### 3. 文章列表与右上文章操作

| 功能键 | 用途 | 影响范围 |
|---|---|---|
| 搜索文章 | 按关键词筛选文章 | 当前所选公众号范围 |
| 全部 / 收藏 / 有正文 / 无正文 / 更新中 / 已删除 | 按文章状态筛选 | 当前文章列表 |
| 列设置 | 显示或隐藏题图、公众号、正文、原创、类型、更新时间、发布时间等列 | 只改变列表显示；标题和操作列固定保留 |
| 在应用内阅读 / 原链接 | 选择标题在爪爪内打开，还是打开原作者文章地址 | 切换后会记住选择 |
| 刷新 | 输入起始页和结束页，更新当前公众号相应页码范围的文章 | 当前选中的公众号 |
| 订阅链接 | 按当前公众号和搜索词选择 ATOM、RSS、JSON、Markdown 或 Text 格式 | 只是打开地址，不会自动添加到外部阅读器 |
| 清理无效文章 | 清理已找不到对应本地公众号记录的文章 | 本地文章数据 |
| 清理重复文章 | 清理重复的本地文章 | 本地文章数据 |
| 清理旧文章 | 按天数和公众号预览，再确认删除旧文章 | 可先点“预览”；确认删除后不可恢复 |
| 批量删除 | 删除当前勾选的多篇文章 | 弹窗会显示篇数；确认后不可恢复 |

### 4. 单篇文章动作

| 图标或动作 | 用途 |
|---|---|
| 眼睛 | 在爪爪内读取文章正文 |
| 收藏 | 收藏或取消收藏 |
| 刷新 | 重新抓取这一篇文章，并等待刷新任务结果 |
| 删除 | 删除这一篇本地文章；确认后不可恢复 |
| 阅读状态图标 | 标记已读或未读 |

> 删除本地文章不会删除原作者在微信中的文章。

> “删除订阅”“删除文章”和“删除导出文件”是三个不同对象：分别影响本地公众号记录、本地文章记录和已经生成的文件。

## 四、三横线菜单：9 个入口速查

高级功能按需要使用即可，不需要第一次进入时把所有菜单都配置一遍。将鼠标悬停在入口上，可以先看功能说明。

### 整理与自动化

| 路径 | 到达界面 | 主要功能键 | 用途和典型场景 |
|---|---|---|---|
| 菜单 → 标签管理 | 标签管理 | 导出、导入、添加标签、订阅、编辑、删除 | 把多个公众号整理成一个标签；标签可生成 RSS 订阅地址 |
| 菜单 → 消息任务 | 消息任务 | 开启浏览器通知、应用、添加消息任务、编辑、测试、执行、删除 | 定时更新关联公众号，并可按模板向自己配置的 Webhook 推送 |
| 菜单 → 过滤规则 | 过滤规则 | 公众号筛选、添加规则、编辑、禁用/启用、删除 | 采集后清理正文 HTML、广告或无关元素 |
| 菜单 → 任务队列 | 任务队列 | 刷新、清空队列、清空历史 | 查看主队列、内容队列和定时调度器状态，排查任务是否堵塞 |
| 菜单 → 采集状态 | 采集状态 | 刷新、分页、排序 | 查看文章数、最近文章、更新状态、最后任务和执行节点 |

### 高级与诊断

| 路径 | 到达界面 | 主要功能键 | 用途和典型场景 |
|---|---|---|---|
| 菜单 → 级联管理 | 级联节点管理 | 创建节点、刷新、手动分发、生成凭证、测试连接、编辑、删除 | 一个人有多台 WeRSS 服务器时，共享采集工作；单机无需配置 |
| 菜单 → Access Key | Access Key 管理 | 创建、复制、编辑、停用、删除 | 给其他程序调用公众号接口使用，不是大模型 API key，也不代替微信扫码 |
| 菜单 → 异常统计 | 环境异常统计 | 查询、今日统计、刷新 | 按日期查看异常总数、异常公众号、异常 URL 和发生时间 |
| 菜单 → 设置与诊断 | 设置与诊断 | 配置信息、系统信息、运行日志、刷新日志 | 查看配置、系统状态和启动/运行问题 |

### 消息任务要点

- 消息任务用于定时更新关联公众号；配好 Webhook 后，可按模板向自己配置的目标地址推送，但不会读取微信私聊或群聊。
- **“测试”** 会真的发送测试消息；**“执行”** 会更新关联公众号；修改后点 **“应用”** 才会重载任务；删除后无法恢复。

### 过滤规则要点

- 过滤规则处理已采集的正文 HTML，可按元素 ID、Class、CSS 选择器、属性或正则表达式移除内容，也能清理脚本、样式等常见元素。
- 多条规则按优先级执行；它不是按文章标题关键词筛选订阅。

### 任务队列要点

- **“清空队列”** 会移除等待中的任务，不会中断正在执行的任务；**“清空历史”** 只删除执行记录，不会删除文章。

### Access Key 要点

- Access Key 是其他程序调用公众号接口的凭证，不是大模型 API key，也不代替微信公众号扫码授权；本 App 只读用途选择 **“读”** 权限即可。
- Secret 只在创建成功时显示一次，应立即保存；停用后密钥立即失效，删除后不可恢复。

## 五、设置与诊断

从右上 **“三横线 菜单”** 进入 **“设置与诊断”**，可以看到三个标签：

| 标签 | 可以做什么 |
|---|---|
| 配置信息 | 查看配置键、配置值和说明；进入详情后可编辑、保存或删除配置 |
| 系统信息 | 查看系统信息和资源使用情况；点击“刷新”会启动文章统计更新 |
| 运行日志 | 查看爪爪集成公众号功能的运行日志；点击“刷新日志”重新读取 |

注意：系统信息里的文章统计“刷新”，只更新统计数据，不等于重新采集公众号文章。

修改或删除配置信息会影响公众号服务行为。小白用户没有明确需求时，保持现有配置即可。

## 六、遇到问题先点哪里

| 遇到的问题 | 先检查或点击 |
|---|---|
| 页面显示未授权 | 主导航“微信授权” → “扫码授权” → 手机微信确认 → “刷新状态” |
| 授权慢但页面已经进入 | 三横线菜单 → “设置与诊断” → “运行日志” → “刷新日志” |
| 公众号启动失败，还没进入页面 | 在启动失败卡片中点击“设置与诊断”展开日志；点击“重试”重新启动 |
| 文章长时间不更新 | “订阅与文章”选择公众号 → “刷新”并设置页码；再看“任务队列”和“微信授权”状态 |
| 导出后找不到文件 | 主导航“导出记录” → “刷新” |
| 只想给公众号分组 | 三横线菜单 → “标签管理” → “添加标签” |
| 消息任务修改后没生效 | “消息任务” → “应用” |
| 怀疑任务堵塞 | “任务队列” → “刷新”，查看主队列和内容队列 |
| 只想查看今天的异常 | “异常统计” → “今日统计” |

## 七、使用说明

- 微信平台使会话失效或授权到期时，请到“微信授权”重新扫码；“刷新状态”只读取当前状态，不延长会话。
- “订阅链接”会按当前公众号和搜索词提供 RSS、ATOM、JSON、Markdown 或 Text 地址，不会自动替你添加到外部阅读器。
- 系统信息中的文章统计“刷新”不负责抓取文章；抓取或更新文章请回到“订阅与文章”使用“刷新”。
