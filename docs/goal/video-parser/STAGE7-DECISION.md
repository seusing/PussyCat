# 阶段 7 收尾决策

## 本轮落地

- 任务详情展示真实的阶段耗时、模型调用次数和 Token 用量。
- 费用明确区分“估算”和“未知”；没有可信单价时不再显示为 ¥0。
- 当前通道无可信单价时，人民币最高费用输入不可用，后端也会拒绝无法兑现的上限。
- 提交区明确说明：为完成解析，提取出的字幕或语音转写会发送到用户选择的第三方模型服务。

## 为什么没有打开并发

当前 runner 的阶段记录依赖共享的 `current_stage_run_id`，预算也依赖共享累计值；直接并发会带来模型调用归属错误、预算竞争、取消顺序不确定等正确性风险。现有真实基准少于 30 条，而且中转站的安全并发和限流边界没有被验证。因此本轮明确不以正确性换取表面速度。

只有同时满足以下条件才重新评估并发：

1. 阶段记录改为上下文隔离，不共享当前阶段 ID；
2. 预算采用原子预留/结算，任何并发顺序都不能越过上限；
3. 取消、重试、主备切换具备确定性的并发测试；
4. 同一硬件、同一模型、同一语料至少 30 次可比运行；
5. p50 有明确改善，且交付成功率、429/5xx、费用均不恶化。
